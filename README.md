Portofolio 
Buka `index.html` di browser. Tidak perlu build atau instalasi.
Font memakai Google Fonts (Bowlby One + DM Sans) dan perlu koneksi internet; tanpa internet, font cadangan sistem dipakai.

Deploy gratis: unggah folder ini ke GitHub Pages, Netlify, atau Vercel.
Edit konten langsung di `index.html`, warna di bagian `:root` pada `style.css`.
